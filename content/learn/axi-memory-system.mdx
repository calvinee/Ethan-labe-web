## 学习目标

能够从吞吐、延时与缓存三个维度设计数据通路，理解 valid/ready 背压和突发访问。

## 核心内容

- AXI4-Stream 握手
- FIFO 深度估算
- AXI4 突发访问
- DDR 带宽与多次搬运成本

## 阶段验收

完成一条带背压和统计计数的流接口，并构建 DDR 环形缓存小项目。
