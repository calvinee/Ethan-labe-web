## 学习目标

理解时钟、复位与跨时钟域的失效机理，能为单比特、脉冲和多比特数据选择合适结构。

## 核心内容

- 亚稳态与同步器
- 异步复位同步释放
- 握手、异步 FIFO 与 Gray Code
- CDC 检查与约束边界

## 阶段验收

完成一个可靠事件传递模块，并用随机相位 Testbench 验证跨域行为。
